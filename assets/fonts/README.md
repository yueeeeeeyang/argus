# 字体资源目录

文件职责：说明 Argus 内置字体资源目录的使用方式。  
创建日期：2026-06-09  
修改日期：2026-10-29
作者：Argus 开发团队  
主要功能：存放经授权后可随程序分发的界面字体与日志阅读字体文件。

## Microsoft YaHei Mono

程序界面和来源树使用 `Microsoft YaHei Mono` 字体族。

该字体由操作系统提供；仓库不包含其字体文件或分发授权。系统未安装同名字体时，使用
平台字体回退机制。若后续取得分发授权，需把字体字节显式加入编译期内嵌和注册流程。

## JetBrains Mono

日志正文显示使用 `JetBrains Mono` 字体族，并由仓库内置的常规字重文件提供：

```text
assets/fonts/JetBrainsMono-Regular.ttf
```

`src/fonts.rs` 通过 `include_bytes!` 将该文件编译进可执行程序，启动时直接注册内嵌字节。
安装包不依赖构建机源码目录、运行目录或外部字体文件。字体注册失败会明确报错。
该字体用于日志行渲染和文本选择命中计算，确保显示宽度与拖选复制位置保持一致。
